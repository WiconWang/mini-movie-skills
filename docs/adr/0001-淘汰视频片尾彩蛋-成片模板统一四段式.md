# 淘汰视频片尾彩蛋（outro_special），成片模板统一四段式

成片组装从「片头 + 正片 + 可选视频片尾彩蛋」改为固定四段式：**Cover（封面图，默认2s）→ 片头（外部视频，可选缩放/位移）→ 正片 body → 片尾（图片，默认2s）**，`composition` 列表未声明的段直接跳过。`outro_special`（视频片尾彩蛋）分支整段删除，连同仅由它使用的 `compose()` `outro_items` 参数与 `_normalize_video()` `trim` 入参一并清理；彩蛋原声片段今后以 raw_insert 形式纳入 EDL 正片，不再单列片尾槽位。

**决策原因**（2026/09/08 评审定案）：片尾统一为图片型与 Cover 同构，省去视频彩蛋的 trim/选段人工环节；彩蛋本就是原声高光内容，归 raw_insert 语义更正。**选了立即删除而非保留弃用分支**：本项目未进生产环境，所有现存任务与物料均为测试产物，不为兼容测试内容留下技术债。hd-14 等测试任务 `composition` 中的 `outro_special` 条目直接删除（含 .bak 文件），无迁移层。

**后果**：`stage_compose` 对外契约变更（`outro_special` 类型不复存在）；新增 `cover`/`outro`（图片型）两个 composition 类型；片头项新增可选 `transform` 字段。既有任务配置需同步清理。A/B 两模式共用此模板（B 模式典型：Cover + raw_insert 拼接 + 片尾，一般无片头）。
