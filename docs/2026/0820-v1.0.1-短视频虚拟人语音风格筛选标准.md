# 短视频虚拟人语音风格筛选标准

> 日期：2026-08-20
> 适用范围：剧情复盘、游戏故事、悬疑调查类短视频
> 定位：作为帐号长期使用的虚拟人旁白声音，不绑定某一个具体 TTS 工具

## 一、推荐结论

推荐使用：

> **成年女性声，中低音区，温柔但冷静，带轻微悬疑感；语速中等偏快，但不急促。**

声音应当像一个投入故事、擅长讲述细节的旁白者，而不是新闻播报员、游戏主播或角色配音演员。

## 二、核心声音画像

| 维度 | 推荐标准 |
| --- | --- |
| 性别 | 女声优先 |
| 年龄感 | 成年、偏年轻，不要少女音 |
| 音区 | 自然中音到中低音 |
| 音色 | 清晰、温暖、略微低沉，有一定厚度 |
| 情绪基调 | 冷静温柔，带轻微好奇和悬疑 |
| 情绪比例 | 约 70% 冷静温柔、20% 好奇悬疑、10% 情绪加强 |
| 语速 | 默认 1.0 倍，建议范围 0.95~1.05 倍 |
| 咬字 | 清晰但不刻意播音腔，角色名和专有名词要稳定 |
| 停顿 | 在转折、反转、身份揭露和疑问前后保留自然停顿 |

## 三、叙事表现要求

### 1. 平稳推进

普通剧情使用自然、平稳的叙述，不持续提高音量或语调。旁白需要让观众能够长时间收听，不能每句话都像高潮。

### 2. 关键节点加强

以下场景可以适当增加语气变化：

- 凶案或危险出现
- 角色身份揭露
- 关键线索被发现
- 原有推理被推翻
- 角色失去重要之人
- 故事进入新的阶段

加强应优先通过语速略降、停顿增加、重音清晰完成，而不是持续激昂或大幅提高音量。

### 3. 悬疑感克制

悬疑感来自信息顺序、停顿和语气收束，不依赖夸张的恐怖腔。疑问句、转折句和结论句应有明显区别，但整体仍保持自然。

### 4. 情绪温度

面对角色的遗憾、误会、牺牲和救赎，可以表现出温柔和惋惜；面对反转和危险，可以表现出紧张和警觉；避免持续煽情、哭腔或过度戏剧化。

## 四、不同场景的语音策略

| 场景 | 语速 | 情绪 | 表达重点 |
| --- | --- | --- | --- |
| 日常铺垫 | 1.0~1.05 | 平静、自然 | 清楚交代人物和背景 |
| 调查线索 | 0.95~1.0 | 冷静、专注 | 让观众跟上因果关系 |
| 新疑问出现 | 0.95 左右 | 好奇、警觉 | 疑问前适当停顿 |
| 重大反转 | 0.9~0.98 | 克制、凝重 | 结论句降低速度并留白 |
| 角色牺牲 | 0.9~0.95 | 温柔、惋惜 | 不使用夸张哭腔 |
| 战斗或高潮 | 1.0~1.08 | 紧张、坚定 | 可以提高力度，但不持续喊叫 |
| 结尾收束 | 0.95~1.0 | 平静、余韵 | 给观众留下思考空间 |

## 五、筛选 TTS 工具时的试听标准

不要只试听单句，至少准备一段包含“铺垫、调查、反转、情绪收束”的完整样稿。重点检查：

- 连续朗读 2~3 分钟后是否疲劳
- 长句和短句之间是否自然切换
- 中文标点是否能产生合理停顿
- 疑问句、转折句和结论句是否有区别
- 人名、地名、组织名和游戏专有名词是否读音稳定
- 同一声音在平静、紧张和惋惜场景下是否都成立
- 语速调整后是否出现吞字、拖音或机械停顿
- 是否能与游戏原声和角色对白区分开
- 是否支持稳定的音色、语速、音量和情绪参数
- 是否支持批量生成、失败重试和长期接口调用

## 六、不建议的声音类型

- 过于甜腻或幼态的少女音
- 持续高亢激昂的主播腔
- 过于低沉厚重、压迫感强的男声
- 平直机械的新闻播报腔
- 明显带广告腔或营销腔的声音
- 情绪变化过大、每句话都像在表演的声音
- 过快导致信息堆叠、观众无法消化的声音

## 七、性别选择说明

女声作为长期帐号声音的优先方案，原因是：

1. 温柔、中性的女声更适合持续讲述复杂剧情，长时间收听压力较低。
2. 中低音女声既能承载悬疑和案件，也能表现角色的遗憾与救赎。
3. 它与游戏中的男性角色、战斗音效和环境声更容易形成区分。
4. 不依赖持续激昂，也能通过停顿和语气变化建立帐号辨识度。

男声可以作为备用方案，但建议选择自然、清晰、偏年轻的中低音男声，不建议使用过度低沉或典型纪录片腔。

## 八、当前 Edge TTS 临时配置建议

项目当前暂时使用 Edge TTS：

```yaml
tts:
  engine: edge
  voice: zh-CN-XiaoyiNeural
  speed: 1.1
```

由于当前文案信息密度较高，临时试听时建议先将语速从 `1.1` 调整到 `1.0`。后续切换到海螺 AI、火山 AI 或阿里云时，应优先寻找符合上述声音画像的音色，不必强行保留当前声音名称或供应商。

## 九、长期帐号风格关键词

选择声音时可使用以下关键词筛选：

> 成年女性、自然中音、中低音、清晰、温暖、冷静、故事讲述、悬疑、耐听、情绪细腻、非播音腔、非幼态。

最终目标不是“最有冲击力的声音”，而是让观众在连续观看多期视频时，能够稳定识别出这是同一个帐号的故事讲述者。
