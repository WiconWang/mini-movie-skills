## 一、项目概述

**项目目标**：将几小时长视频剧情录像 + 准确台词文稿，自动浓缩为十几分钟的解说短视频。

**命令行入口**：`mmm`（mini-movie-maker 缩写），基于 typer 的 Python CLI。

**技术栈**：Python 3.11+ / ffmpeg / faster-whisper / difflib / SQLite / OpenAI 兼容 LLM 网关

**核心流水线**：7 个阶段顺序执行，阶段 1-4 逐视频处理，阶段 5-7 任务级处理。两个闸口（阶段5后审稿、阶段6后审片）需人工确认。
