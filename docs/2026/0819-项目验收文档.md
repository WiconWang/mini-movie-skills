## 一、项目概述

**项目目标**：将几小时长视频剧情录像 + 准确台词文稿，自动浓缩为十几分钟的解说短视频。

**命令行入口**：`mmm`（mini-movie-maker 缩写），基于 typer 的 Python CLI。

**技术栈**：Python 3.11+ / ffmpeg / faster-whisper / difflib / SQLite / OpenAI 兼容 LLM 网关 / pyJianYingDraft

**核心流水线**：7 个阶段顺序执行，阶段 1-4 逐视频处理，阶段 5-7 任务级处理。两个闸口（阶段5后审稿、阶段6后审片）需人工确认。双导出器：A=ffmpeg 直出 MP4，B=剪映草稿。

## 三、BUG 状态追踪

### BUG-1：stage_render.py 缺少 import re [P0 · ✅ 已修复 818709b]

**位置**：`src/mmm/stage_render.py` 第 120 行

**状态**：v2 发现，v3 复查确认 `except Exception: return False` 会静默吞掉 NameError，
导致 ASS 硬字幕永远不触发、静默降级为 SRT 软字幕。**已修复**：文件头补 `import re`。
（注：修复后实测本机 brew ffmpeg 无 libass，`_has_ass_filter()` 返回 False 属真实情况，
SRT fallback 是当前机型的正确路径，非 bug 残留。）

### BUG-2：BGM ducking 时间轴错位 [P1 · ✅ 已修复 818709b]

**位置**：`src/mmm/stage_render.py` `_bgm_duck_regions()`

**状态**：v2 发现，v3 时字幕部分已修（`_output_spans` + `seg_durations`）、BGM 未修。
**现已全部修复**：`_bgm_duck_regions(clips, seg_durations)` 与字幕同源改用成片时间轴累计，
`stage_render.run()` 传入渲染实测片段时长（含 TTS 冻结补齐）。成片时间轴校验单测通过。

### BUG-3：PROGRESS.md 未同步 [P3 · ✅ 已修复 818709b]

PROGRESS.md 已同步：阶段7打磨标完成、断点续跑标完成、导出器B 标完成。

### BUG-4：剪映模块跨模块调用私有函数 [P3 · ✅ 已修复 00448b0]

**位置**：原 `src/mmm/stage_jianying.py` 调用 `stage_render._duration` 私有函数。

**已修复**：ffprobe 时长探测提为公共模块 `src/mmm/media.py` 的 `probe_duration`，
`stage_render` / `stage_jianying` 均改用公共 API，模块内私有 `_duration` 已删除。
