# 物料规范 · mini-movie-maker 输入契约

> 日期：2026-08-17
> 状态：v1
> 读者：素材爬取/整理工具的开发者。管线（mmm）只消费符合本规范的物料，规范之外的格式概不保证。

---

## 1. 总览

管线消费三类输入：**视频、台词文件、台账登记**。本规范定义它们的格式与验收标准。

```
materials/
└── {video_id}/
    ├── source.mp4          # 视频（规范见 §2）
    └── script.jsonl        # 台词文件（规范见 §3，可挂 task 级，见 §4）
```

## 2. 视频规范

| 项 | 要求 | 说明 |
|----|------|------|
| 内容 | **纯剧情实录** | 不得包含第三方口播/实况主声音/后期配音解说 |
| 容器/编码 | mp4（h264/h265） | 其他格式需自行转码后入库 |
| 分辨率 | ≥1080p 建议 | 影响抽帧视觉理解质量；不做硬性拒绝 |
| 音轨 | 必须含原始语音音轨 | 无声视频无法走台词对齐 |
| 命名 | 文件名不限，以目录 `video_id` 为准 | video_id 由登记时分配，不编码业务含义 |

**多视频拆分**：一个章节录成多段视频时，按剧情顺序拆为多个 video_id，任务以 seq 引用（见 §5）。拆分点无特殊要求，管线在任务全局时间轴上合流。

## 3. 台词文件规范（核心）

**格式：JSONL**（每行一个 JSON 对象，UTF-8 无 BOM）。

```jsonl
{"speaker": "派蒙", "text": "看！天上那个就是「群玉阁」了。"}
{"speaker": "？？？", "text": "住手！何事喧哗？"}
{"speaker": null, "text": "旁白或无说话人的台词。"}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `text` | 是 | 台词原文。只清除标记（HTML/模板语法），**不做改写**：保留原始标点、全半角、语气词 |
| `speaker` | 否 | 说话人，无则 `null`。`？？？` 等未揭晓角色原样保留 |

**硬性规则**：

1. **只收有配音的台词行**——无配音的选项文本、系统提示、战斗语音文字一律不得出现
2. **顺序即剧情顺序**——行的先后必须与视频中的语音顺序一致（管线不做乱序重排）
3. **分支台词全收**——互斥分支的台词按文稿顺序全部收录，视频未走的分支在对齐中自然落空，无需标注
4. **一行一句，按「句」拆分**——以游戏内一屏字幕为粒度：采集源若将一个对话回合合并为长段，产出 JSONL 时必须按句末标点（`。！？；…`，含闭合引号/括号）拆分为多行。拆分粒度直接决定对齐锚点密度与字幕断行质量，**长段不拆视为不合格物料**
5. **禁止混入**：场景描述、动作提示、章节标题（这些可作为元数据另行提供，见下）

**可选元数据**（同名 `.meta.json`，有则利用，无则跳过）：

```json
{
  "sections": [{"title": "前往天衡山", "start_line": 1}],
  "characters": ["派蒙", "刻晴", "甘雨"],
  "source_url": "https://wiki.biligame.com/ys/浮城"
}
```

## 4. 台词的挂载层级

| 场景 | 挂载方式 |
|------|---------|
| 一份台词 ↔ 一个视频（常态） | 放 `materials/{video_id}/script.jsonl` |
| 一份台词横跨多个视频 | 放任务级：`tasks/{task_id}/script.jsonl`，task.json 中显式引用；任务级优先于视频级 |

## 5. 台账登记（catalog.yaml）

每条素材登记一行，字段：

```yaml
- video_id: gs-043          # 必填，分配后不变
  series: 原神              # 必填，关联类型适配层配置
  version: "4.3"            # 可选，参与命名模板
  chapter: 罪人舞步旋        # 可选，参与命名模板
  path: materials/gs-043    # 必填
```

## 6. 验收标准（`mmm add` 预检项）

| 检查 | 通过标准 | 失败处理 |
|------|---------|---------|
| 视频可读 | ffmpeg 能探测到视频流与音频流 | 拒绝登记 |
| 台词格式 | JSONL 逐行可解析，`text` 非空 | 拒绝登记，报行号 |
| 标记残留 | text 中无 `<...>` 标签、`{{...}}` 模板 | 警告并自动清除 |
| 行数 sanity | 行数 > 0；与视频时长粗匹配（过少报警） | 警告，可强制通过 |
| 行长 sanity | 单行 > 50 字疑似未按句拆分（规范 §3 第4条） | 警告，报行号 |
| 编码 | UTF-8 | 拒绝登记 |

**对齐阶段覆盖率**（M1 验收线）：匹配行数 / 总行数 ≥ 95%，时间戳抽片人工核对误差 < 0.5s。低于 85% 报警转人工核查物料。
