## 五、质量数据分析

### 解说稿（narration.md）

- 30 句 / 1558 字，覆盖 2.3s-1666.3s 完整情节弧
- 每句引用台词 ID + 时间区间，讲述故事风格（非机械复述）
- 第一句："派蒙在蒙德城看到了可莉，可莉迎上来，说自己刚想去找他们，因为收到了一封好可怕的信。"
- 最后一句："琴团长对旅行者说，请放心探索，如果有危险她会及时赶到，但愿海岛上没有太多麻烦。"

### EDL 结构

- 28 片段：26 个 narration_clip + 2 个 raw_insert
- raw_insert 片段：300-330s（第 5 分钟处原声保留）、600-615s（第 10 分钟处保留）
- EDL 按 (视频 seq, 源内 start) 排序，raw_insert 与解说按源时间合流
- 每片段含 candidates（最多 5 个候选镜头）+ frames（抽帧路径）+ shot_ids

### 画面分级分布

| 级别 | 数量 | 占比 |
|------|------|------|
| E（过场） | 0 | 0% |
| D（无台词运镜） | 0 | 0% |
| C（高动态） | 0 | 0% |
| B（对话有运镜） | 24 | 8.8% |
| A（静态对话） | 249 | 91.2% |

**风险**：91% 是 A 级，选片画面丰富度有限。但 hd-p1 真实出片已验证可用，选片排除了操作界面镜头（`_is_ui_only`），实际效果需观看成片判断。

### 字幕

- ASS 硬字幕（libass 渲染）：Noto Sans CJK SC 42px，白字描边 2.5px，底部居中
- SRT 软字幕（fallback）：同时间轴
- drawtext 硬字幕（无 libass 时）：PingFang 42px，白字描边 3px
- 语义断行：优先标点切分，每屏 <=18 字，每行 1.0-6.0s

### BGM

- 全局基础音量 0.5（-6dB，用户要求整体压低 50%）
- 解说段再 -14dB（合计 -20dB）
- raw_insert 段再 -6dB（合计 -26dB），结束后自动恢复基础音量
- 2s crossfade 衔接，loudnorm 标准化
