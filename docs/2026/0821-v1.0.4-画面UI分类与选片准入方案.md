# 画面 UI 分类与选片准入方案 v1.0.4

> 版本：v1.0.4
> 日期：2026-08-21
> 定位：v1.0.0 画面分级表的**补丁与增强**，不改 v1.0.0 原文档
> 背景：实测发现 v1.0.0 分级表存在漏洞——"无台词 + 有操作 UI"（跑图/战斗）镜头落空被误塞 A 级；且 vision 的 `has_dialogue_scene` 信号实测全失效（746 个对话镜头全标 False）。本方案补漏洞 + 把 UI 信号从 bool 升级为三分类，并加选片准入门槛。
> 关联：v1.0.0 `0817-v1.0.0-长视频浓缩工作流.md` §2 画面分级；v1.0.2 `0821-v1.0.2-vision阶段加速方案.md`（本方案在其并发/拼图基础上只改 prompt）。

---

## 1. 与 v1.0.0 的关系（兼容增强，非推翻）

**v1.0.0 E→A 分级表不动**，只在外层加一层 ui_type 准入门槛：

```
v1.0.0：shots → (黑白屏 + has_ui + 台词覆盖 + motion) → E~A 分级 → select 按 E→A 选
v1.0.4：shots → vision 打 ui_type → [准入门槛: gameplay 否决] → 准入的按 v1.0.0 E→A 分级 → select 按 E→A 选
```

补的漏洞：v1.0.0 E/D 要求"无 UI"、C/B/A 要求"有台词"，"无台词 + 有操作 UI"镜头不满足任何规则落空，被默认塞 A 级。v1.0.4 让这类镜头（ui_type=gameplay）直接一票否决，不参与分级。

---

## 2. ui_type 三分类定义

vision prompt 把 `has_ui`(bool) + `has_dialogue_scene`(失效) 合并为单一信号 `ui_type`：

| ui_type | 含义 | 选片准入 | 归入 v1.0.0 分级 |
|---------|------|---------|----------------|
| `none` | 无任何 UI（过场动画/空镜/环境镜头） | ✓ 准入 | E / D |
| `dialogue` | 对话框/对话分支选项（剧情演出画面） | ✓ 准入 | C / B / A |
| `gameplay` | 血条/小地图/任务追踪/技能图标/菜单/地图界面/商城/弹窗等操作界面 | ✗ **一票否决** | 不分级（排除） |

### 单选规则（gameplay 优先否决）

ui_type 单选，按"最差优先"：**有 gameplay 元素即算 gameplay**（即使同时有对话框）。最严，符合"不要操作界面"的强诉求。例如战斗中弹出对话框的镜头，判 gameplay。

---

## 3. raw_insert 兼容（gameplay 极低概率手动选入）

用户非常喜欢某 gameplay 片段时可手动指定保留，兼容办法三层：

| 层 | 机制 | 改动 |
|----|------|------|
| 1. 天然豁免 | raw_insert 走 task.json `keep_requirements` 直接切原片进 EDL，不经 `_collect_candidates` 候选筛选 → ui_type 准入规则对 raw_insert 完全不生效 | 零改动 |
| 2. 可见性 | 分镜板 storyboard.html 标注 raw_insert 片段的 ui_type，闸口2 人工可见可改 | storyboard 渲染加字段 |
| 3. 提醒 | keep_requirements 区间若含 gameplay 镜头，select 时打印一行提醒（防用户没意识到该段是跑图画面） | select 加检测 |

**结论**：gameplay 作 raw_insert 自动兼容，用户手动指定即保留，UI 也认。提醒机制避免误指定。

---

## 4. 三处代码改动

### 4.1 `src/mmm/stage_vision.py`（prompt 改）

PROMPT 把 `has_ui` + `has_dialogue_scene` 两信号合并为 `ui_type`：

```json
{
  "description": "...",
  "ui_type": "none" | "dialogue" | "gameplay",
  "motion": "static/low/medium/high",
  "is_cutscene": true/false
}
```

单选规则写入 prompt：有 gameplay 元素（血条/小地图/任务追踪/技能/菜单/地图/商城/弹窗）即判 gameplay，即使同时有对话框。

`analyze_shot` 输出 schema：`ui_type` 替代 `has_ui` + `has_dialogue_scene`。拼图+并发+≤2s 废弃（v1.0.2）保留不变。

### 4.2 `src/mmm/stage_index.py`（准入层）

分级逻辑加准入门槛：
- `ui_type == "gameplay"` → 标记 `_excluded: "gameplay"`，不参与 E~A 分级
- `ui_type in {"none", "dialogue"}` → 按 v1.0.0 规则分级：
  - E：黑白屏边界 + ui_type=none + 无台词
  - D：无台词 + ui_type=none + 有运镜
  - C：有台词 + 高动态
  - B：有台词 + 有运镜
  - A：有台词 + 静态对话

### 4.3 `src/mmm/stage_select.py`（准入过滤）

`_collect_candidates` 加准入过滤：
```python
cands = [s for s in cands if s.get("ui_type") != "gameplay"]   # 准入门槛
cands = [s for s in cands if (s["end"] - s["start"]) >= 2.0]    # ≤2s 废弃（v1.0.2）
```
删除失效的 `_is_ui_only` 关键词匹配（被 ui_type 取代，关键词匹配有漏检）。

raw_insert 提醒（可选）：keep_requirements 区间内若含 gameplay 镜头，select 时打印提醒。

## 8. 风险与权衡

- **ui_type 判准度**：VLM 对"操作界面 vs 对话框"的区分能力需验证（重跑后抽检）。单选"gameplay 优先否决"偏严，可能误杀少数"战斗中对话"镜头——可接受（严比松好）。
- **素材量**：排除 gameplay 后剩余 B+C 镜头（用台词近似估 76 分钟，v1.0.4 后会更准），5 倍于 15 分钟目标，充足。
- **P2 解谜段**：gameplay 占比高，排除后候选少，可能触发兜底（标 needs_review），闸口2 人工补。符合预期（解谜段本就画面价值低）。
- **历史 vision 数据**：v1.0.4 后旧 shots_meta 全废，不能混用（schema 变了：ui_type 替 has_ui）。重跑时 `--force` 或删 shots_meta 目录。

# v1.0.5 补丁：过场升级垫（is_cutscene 参与分级）

> 版本：v1.0.5 ｜ 日期：2026-08-21 ｜ 定位：v1.0.4 的分级增强，不改 v1.0.4 准入逻辑
> 背景：实测发现"升岛动画"类高价值长过场未入选——句34（"整片陆地竟从海面下升了起来"）对应 shot 55（p3 本地 385.7-397.7s，12s，远景→黑屏转场→角色背影+升起岛屿），画面价值极高却被判 A 级，选片时被 D/B 级 2-3s 空镜优先填满配额，漏选。

## 根因

1. **v1.0.0 分级表未消费 vision 的 `is_cutscene` 信号**——电影化过场演出（含运镜/黑屏转场/长镜头）与普通空镜/静态对话在 A 级内不分高下。
2. shot 55 是 `ui_type=dialogue + is_cutscene=True + 12s`：因有台词落 A（B 需 motion≥2，A 兜底），而 3-6s 空镜（none+cutscene）反而拿 D/B。

## 规则（改 `stage_index.classify`）

在 v1.0.4 E~A 判定之后加"过场升级垫"：

```
is_cutscene=True 的镜头：至少 B 级；时长 ≥6s 的长过场：至少 C 级；只升不降
```

- E > D > C > B > A 序取更优，不覆盖已有更高分级（shot 38 现 D 保持不变）。
- 新增 `CLASS_RANK` 常量与 `stage_select.CLASS_RANK` 对齐。

## 验证（2026-08-21）

| 镜头 | 内容 | 时长 | 旧→新 |
|------|------|------|--------|
| p3 shot 55 | 升岛动画过场 | 12s | A → **C** ✅ 句34 已选中 |
| p3 shot 49 | 岩石瀑布拉远 | 7.4s | B → C |
| p3 shot 40 | 俯瞰空镜 | 3.9s | A → B |
| p3 shot 38 | 草地过场 | 3.6s | D → D（只升不降） |

全局分级分布：E0 D5 **C 2→49** **B 81→161** A 670→543 X181。句34 片段 shot_ids 变为 [38,49,55,40]，覆盖升岛动画。
